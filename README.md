# Портфолио веб-разработчика

## О проекте

🚀 Этот проект — SPA (Single-page App) & PWA (Progressive Web App)

⚙️ Использует Vite с кастомной конфигурацией в качестве сборщика и dev-сервера

🔧 Основные зависимости: Vue 3, Vue Router, Sass/SCSS

✅ Весь HTML семантичный и доступный, навигация полностью работает с клавиатуры

🎨 Стилизация с использованием BEM-нейминга

📱 Адаптивная вёрстка, протестированная на всех разрешениях экрана

🎞 CSS-анимации на всех страницах с плавными переходами

🗄 Данные UI сохраняются в localStorage (фильтр портфолио)

📊 Аналитика через Яндекс.Метрику с SPA-трекингом (каждый переход фиксируется как отдельный просмотр)

🧹 Чистый и единообразный стиль кода с использованием Prettier & ESLint

💪🏻 Всё сделано самостоятельно: дизайн, код, тексты, интеграции, деплой

🏎 Оценка Google Page Speed: ~96

---

## Технологии

- **Vue 3** (Composition API)
- **Vue Router**
- **Vite**
- **Sass/SCSS**
- **ESLint + Prettier**
- **PWA** (vite-plugin-pwa)
- **@iconify/vue**
- **Яндекс.Метрика** (webvisor, clickmap, SPA hit)

---

## Команды

```bash
npm install        # установка зависимостей
npm run dev        # запуск dev-сервера
npm run build      # сборка для production (dist/ → загрузить на хостинг)
npm run lint       # проверка кода
npm run format     # форматирование кода
```

## Известные ограничения / TODO

- **Карта на странице контактов** использует стандартный Яндекс iframe-виджет. Из-за ограничений iframe невозможно убрать встроенные UI-контроли (масштаб, ссылку «Открыть в Яндекс Картах»). Для полного контроля над отображением необходимо перейти на [Яндекс Maps JavaScript API](https://developer.tech.yandex.ru/) с API-ключом.
